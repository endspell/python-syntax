python.syllabus

Python, start to finish.

A complete Python-only course in three phases. No frameworks, no AI or ML. Just the language, its standard library, and the engineering habits around it.

3phases
12projects

Phase 1: Beginner

6 to 8 weeks. Write and run your first programs.

Getting started
  • What Python is, installing it, the REPL, running scripts
  • Code editors and IDEs (VS Code, PyCharm)
  • pip and virtual environments (venv)
  • Comments, indentation, naming rules
Core syntax
  • Variables, numbers, strings, booleans, None
  • Type conversion and dynamic typing
  • Arithmetic, comparison, logical, bitwise, and assignment operators
  • Input and output, f-strings, string formatting
Control flow
  • if / elif / else, match statements
  • for and while loops, range, enumerate, zip
  • break, continue, pass, loop else
Data structures
  • Strings: slicing, methods, immutability
  • Lists, tuples, sets, dictionaries
  • Mutability, copying (shallow vs deep), unpacking
  • List, dict, and set comprehensions
  • Sorting, searching, and common built-ins (len, sum, min, max, any, all)
Functions
  • Defining functions, return values, docstrings
  • Positional, keyword, default, *args, **kwargs
  • Scope (LEGB), global, nonlocal
  • Lambda, map, filter, recursion
Modules and files
  • Imports, creating your own modules and packages
  • Standard library tour: math, random, datetime, os, sys, pathlib
  • Reading and writing text, CSV, and JSON files
  • Exceptions: try, except, else, finally, raise
Developer basics
  • Command line essentials
  • Git and GitHub: commit, branch, merge, pull request
  • Reading tracebacks, debugging with print and pdb
  • PEP 8 and clean code habits

Projects

Calculator, number guessing game, CLI to-do list saved to JSON, file organizer.

Phase 2: Intermediate

8 to 10 weeks. Write structured, reusable, tested code.

Object-oriented programming
  • Classes, objects, __init__, instance vs class attributes
  • Methods: instance, @classmethod, @staticmethod
  • Inheritance, super(), multiple inheritance, MRO
  • Encapsulation, @property, polymorphism, abstract classes (abc)
  • Dunder methods: __str__, __repr__, __eq__, __len__, __iter__
  • dataclasses and enum
Functional and iterator tools
  • Iterables, iterators, and the iterator protocol
  • Generators, yield, generator expressions
  • Closures and decorators (with arguments)
  • functools (lru_cache, partial, wraps) and itertools
  • Context managers and the with statement
Standard library in depth
  • collections: Counter, defaultdict, deque, namedtuple
  • re regular expressions
  • json, csv, pickle, shelve
  • argparse, subprocess, shutil, glob
  • datetime and time zones with zoneinfo
  • sqlite3 for databases
  • urllib and http.client
  • logging
Quality and tooling
  • Type hints, typing, static checking with mypy
  • Unit testing with unittest and pytest, fixtures, mocking
  • Linting and formatting (ruff, black)
  • Project layout, pyproject.toml, requirements files
  • Debugging with pdb and IDE debuggers
Working with data in pure Python
  • Parsing and generating CSV, JSON, XML
  • Text processing and string algorithms
  • Handling dates, money (decimal), and fractions
  • Basic algorithms: sorting, searching, recursion, big-O
  • Core data structures: stack, queue, linked list, tree, graph, heap

Projects

Library management system (OOP), log file analyzer, command-line contact book with SQLite, text-based adventure game, tested utility package.

Phase 3: Advanced

12 to 16 weeks. Understand how Python works and make it fast, concurrent, and shippable.

Python internals
  • CPython, bytecode, the dis module
  • Memory management, reference counting, garbage collection
  • The GIL and what it means for performance
  • Object model, __slots__, descriptors, attribute lookup
  • Import system and module loading
Advanced language features
  • Metaclasses and class decorators
  • __getattr__, __call__, __new__, operator overloading
  • Advanced decorators and decorator factories
  • Generics, Protocol, TypedDict, Literal, overload
  • Structural pattern matching in depth
  • Coroutines and the yield from mechanism
Concurrency and parallelism
  • threading, locks, queues, thread pools
  • multiprocessing, process pools, shared memory
  • concurrent.futures
  • asyncio: tasks, event loop, async iterators, gather
  • Choosing between threads, processes, and async
  • Race conditions, deadlocks, thread safety
Performance
  • Profiling with cProfile, timeit, tracemalloc
  • Algorithmic and data-structure optimization
  • Memory efficiency, generators, array, memoryview
  • Calling C code with ctypes and an intro to C extensions
Networking and systems
  • Sockets: TCP and UDP clients and servers
  • Building a simple HTTP server with http.server
  • Working with the file system, processes, signals
  • Serialization, compression (zipfile, gzip), struct
  • Cryptography basics: hashlib, hmac, secrets
Design and architecture
  • SOLID principles, composition over inheritance
  • Design patterns: singleton, factory, observer, strategy, adapter
  • Clean code, refactoring, code review
  • Error-handling strategies, custom exception hierarchies
  • Documentation with docstrings and Sphinx
Packaging and delivery
  • Building and publishing packages (wheel, build, PyPI)
  • Semantic versioning, changelogs
  • Command-line tools with entry points
  • Continuous integration with GitHub Actions
  • Test coverage, property-based testing (hypothesis)

Capstone projects (pick 2 or 3)

Multithreaded web crawler, async chat server over sockets, your own mini testing framework, a CLI tool published to PyPI, a task scheduler with persistence, an interpreter for a small language.

Tip: finish each phase's projects before moving on. Reading builds familiarity; building builds skill.
